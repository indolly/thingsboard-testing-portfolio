- 集合包含36个请求和36个测试脚本；

- 失败时附加脱敏后的请求与响应。

## 4. 典型问题与闭环

| 问题 | 分类 | 处理与结果 |
|---|---|---|
| Postman通过代理访问`localhost`时连接异常 | 工具/网络环境 | 关闭Postman代理并使用`127.0.0.1`后恢复 |
| 告警恢复遥测已保存但告警不清除 | 测试配置 | 修正设备配置中的清除条件后回归通过 |
| Jenkins回归出现4个失败、30个初始化错误 | 环境 | 定位为Docker Desktop未运行、9091端口未监听；启动环境后回归成功 |
| 非法资产ID查询关系返回404而不是空数组 | 接口行为理解 | 根据实际API语义调整预期，保留404断言 |
